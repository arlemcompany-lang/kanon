# CLAUDE.md — jp（日本向けファン案内ページ）

## このフォルダについて
日本のファン向けの案内ページ。日本語のみ（言語切替バーは無い）。
トップページ（`../index.html`）から、**日本語表示のときだけ**ボタンが出て移動する。

公開URL：https://arlemcompany-lang.github.io/kanon/jp/

## ファイル構成
```
jp/
├── CLAUDE.md    このファイル
├── index.html   案内ページ本体
└── guide.css    このページ専用のスタイル
```

## デザインの決まり
- **色とフォントはトップページと共通**。`../css/style.css` を先に読み込み、
  その後 `guide.css` で案内ページ専用の部品だけを足している
- 色を変えたいときは `../css/style.css` の `:root` を触る（両ページに反映される）
- `guide.css` に色を直接書かない。必ず `var(--wine)` などの変数を使う

## 中身の書き換え方
HTML内の `<!-- ▼ ... -->` が書き換え待ちの箇所。全て日本語で直接書いてよい。

| セクション | 中身 |
|-----------|------|
| 01 はじめに | 本人からのあいさつ文 |
| 02 2つのサイトについて | myfans / OnlyFans の比較表（料金・支払い方法など） |
| 03 登録のしかた | 4ステップ。実際の画面に合わせて書き換える |
| 04 お願い | 転載禁止などのお願い |
| 05 よくある質問 | `<details>` の開閉式。増減は要素ごとコピー／削除 |

## 注意
- このページは日本語専用なので `data-i18n` は使わない
- トップページ側のボタンは `data-only-lang="ja"` で出し分けている。
  この属性を消すと全言語で表示されるので消さないこと
