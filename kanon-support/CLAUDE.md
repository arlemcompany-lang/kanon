# CLAUDE.md — kanon-support（支援サイト）

## このフォルダについて
kanon トップページとは**別ページ**。日本語のみ。用途は2つ。

1. **お小遣い（支援）を受け取る** — どなたでも
2. **男優・撮影スタッフの募集** — myfans サブスク加入者限定

公開URL：https://arlemcompany-lang.github.io/kanon/kanon-support/

## ファイル構成
```
kanon-support/
├── CLAUDE.md     このファイル
├── index.html    本体
└── support.css   このページ専用のスタイル
```

## デザインの決まり
- 色とフォントはトップページと共通。`../css/style.css` を先に読み、
  そのあと `support.css` で支援サイト専用の部品を足す
- 色を変えるときは `../css/style.css` の `:root` を触る
- `support.css` に色を直接書かない。必ず `var(--wine)` などの変数を使う

## 運用上ぜったいに崩してはいけない設計
このページは**「支援」と「募集」を切り離した状態**で作ってある。理由は法律。

- **お金を払った人が出演できる、という導線にしない。**
  支払いと出演がセットになると、売春防止法上の勧誘にあたるおそれがある。
  「金額によって出演・待遇が変わることはありません」の一文は消さないこと
- 募集の条件は「myfans 加入者であること」であって、「お金を払えば出られる」ではない
- 応募ページに**年齢確認（身分証の提示）**の記載を必ず残す

## AV出演被害防止・救済法（2022年6月施行）の記載
`.s-legal` ブロックに記載済み。以下は法律上の要件なので、文言を弱めたり削除したりしない。

- 出演契約は書面で交わす
- 契約書面の交付から撮影開始まで1か月以上あける
- 撮影終了から公開まで4か月以上あける
- 公開から1年間は無条件で契約を解除できる
- 撮影内容は事前にすべて説明する

## 応募の流れ（確定）
1. 購入のスクリーンショットを送る（myfans 加入の確認）
2. 抽選
3. 当選した方にご連絡（落選の連絡はしない）
4. 本人確認（身分証）
5. 内容の説明と書面での契約 → 撮影は1か月以上あと

- **「当選しても辞退できます」の枠（`.s-callout`）は消さないこと。**
  抽選で当てられた側が断りにくくなるのを防ぐための記載
- 4・5 はユーザー指定の4ステップには無いが、年齢確認と書面契約は法律上の要件なので残している
- スクショについて「支払い情報が写っていたら消して送る」の注意も残すこと

## 応募フォーム（ページ内に埋め込み）
Googleフォームは使わない。**画像添付のたびに応募者へGoogleログインを強制してしまい、
匿名性を保ちたい応募者が離脱するため。** 自作フォーム＋GASでスプレッドシートに転記する。

| ファイル | 役割 |
|---------|------|
| `index.html` 内の `.s-form` | フォーム本体（ページ埋め込み） |
| `index.html` 末尾の `<script>` | 入力チェック・画像圧縮・送信 |
| `gas/Code.gs` | GAS側。スプレッドシート追記 ＋ Drive保存 ＋ メール通知 |
| `gas/appsscript.json` | ウェブアプリ設定（全員アクセス可・実行は自分） |
| `gas/.clasp.json` | clasp の設定。`rootDir` は `.`（gasフォルダ自身） |
| `Code_貼り付け用.txt` | 手で貼るとき用の控え（内容は gas/Code.gs と同じ） |

| スクリプトID | `1fJI8O0d78hgTNNWS6apGJHgC_B6irFsXnYDuZzpzp2E09rFI91jG4ZrY` |

- **更新方法**：`gas/` に入って `clasp push -f` → `clasp deploy --deploymentId <ID>` で同じURLのまま更新
- **保存先のIDは Script Properties に持たせている**（`SPREADSHEET_ID` / `FOLDER_ID`）。
  コードにIDを直接書かない。`setup()` を実行すると無ければ自動で作られる

**受け取る項目**：希望する役割 / myfansアカウント名 / 購入スクショ / 確認事項3つ / ひとこと

**受け取らない項目（意図的）**
- メールアドレス・電話番号 … 当選連絡は myfans のDMで行うので不要
- 身分証 … 応募段階では絶対に集めない。当選連絡のあと別手段で確認する。
  Code.gs にこの処理を足さないこと

**画像の扱い**
- 送信前にブラウザ側で長辺1200px・JPEG品質0.75に圧縮している（送信失敗を防ぐため）
- Drive に保存し、共有設定は変更しない（フォルダにアクセスできる人だけが見られる）
- 選考が終わったら「状態」列を `削除可` にして `cleanupScreenshots()` を実行すると、
  スクショだけ削除できる

**送信の仕組み**：`mode:'no-cors'` ＋ Base64化したJSONをPOST。
ヒヤリングシートで実績のある方式に合わせている。
